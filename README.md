# Collected Observations

Collected Observations is a photography portfolio created by Iman.

The website presents photographs of flowers, microscopic details, animals, landscapes, the moon, and stars. The design uses a dark editorial style inspired by minimalist photography websites.

## Features

- Full-screen animated introduction
- Separate gallery page
- Responsive layout
- Custom cursor
- Smooth navigation
- Black-and-white photographs that reveal colour while scrolling
- About and contact sections

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` — homepage
- `gallery.html` — full gallery
- `styles.css` — website styling
- `script.js` — cursor, typing effect, and image reveal
- `images/` — photographs
- `design/` — project design and screenshots
